# Проверенные и непроверенные способы получения данных

15.11.2026. Полный перебор всех возможных способов не выполнен и не
объявляется выполненным. Отказы отдельных запросов не доказывают, что
никакого разрешённого источника не существует.

Текущее требование владельца — постоянный сбор без его телефона и ПК.

| Направление | Реальная проверка | Что остаётся непроверенным |
|---|---|---|
| Прямой серверный клиент | Проверенный TLS и RPC401 до входа; собственный клиент установлен | Первоначальный игровой вход, продление, UID и история |
| Извлечение ключа из телефона | TECNO LI7, Android15, игра1.1.0, release/debuggable=false; прочитаны логи только процесса игры, включая перезапуск | Ключ в доступных логах не найден; это не доказательство отсутствия его внутри закрытого процесса |
| Внешние файлы игры | Ограниченная проверка своих external files/cache, до глубины2; целевой поиск журналов/конфигов/auth-имён не нашёл файлов | Более глубокие/закрытые каталоги и память не исследованы; root/перепрошивка не выполнялись |
| Обычный UI игры / OCR | В этой сессии экраны профиля и матчей не прочитаны | Не соответствует постоянному сбору без личного телефона; самостоятельная серверная Android-среда требует отдельного теста |
| VK / Bolt ID | Исследованы схемы и официальные OAuth-процедуры; из публичного manifest установленной игры получена scheme `vk54188984` | Игровой вход, verifier/verification и продление; схема не определяет весь OAuth URL |
| So2Stats, открытый рейтинг | Обычный публичный HTML содержит UID, ники, MMR, счётчики и даты | Это не список последних20 матчей произвольного UID |
| So2Stats, наш UID | Публичный `/player/202777998` вернул404 с сообщением «профиль пока не сохранён» | Это не означает, что игрока нет; авторизованный поиск не выполнялся |
| So2Stats, сохранённый профиль | Одна публичная ссылка рейтинга `/player/16260223` вернула200 с карточкой; статистика обозначена доступной после Telegram-входа | Матчи/KDA/участники не получены; серверный API/экспорт не согласован |
| API стороннего поставщика | Изучены публичные страницы/условия; выдача матчевого сервисного ключа не подтверждена | Партнёрский доступ не запрашивался, сообщения поставщикам не отправлялись |
| Официальный магазин | Прямой UID lookup получил403; обычная браузерная главная отдельно открылась200 без challenge | Браузерный поиск и матчевые возможности не проверены; магазин не объявлен источником истории |
| Официальная выгрузка своих данных | Издатель описывает форму Account Data | Архив не запрашивался; формат и наличие поматчевых полей неизвестны; это не доступ к любому UID |
| Реплеи / матчевые файлы | Актуальный документированный формат импорта не найден | Живой реплей/экспорт не получен; старый FAQ не доказывает отсутствия нынешней возможности |

профиль и матчи UID202777998 по-прежнему не получены.

## Дополнительная проверка GitHub

15.11.2026 повторно проверены исходники и открытые изменения AstandyClient.
`main` остаётся на [commit 2976a676](https://github.com/BonePolk/AstandyClient/commit/2976a676e199d6f51959ceacc6016b3d127cd12d)
от 09.06.2026; опубликованных Releases нет. Дата обновления metadata
репозитория сама по себе не означает обновления кода.

Дополнительно просмотрен [PR 2](https://github.com/BonePolk/AstandyClient/pull/2)
и его критические файлы: изменения TLS и RPC-схем не добавляют получение
первоначального ticket. Его
[handshake.py](https://github.com/punchbiter/AstandyClient/blob/79dbafea78f7f55be24d7ce2d17c74b767f6bb3a/Astandy/services/handshake.py)
продолжает отправлять уже переданный ticket. Это не проверенная процедура
входа в нынешнюю игру по почте и паролю.

Собственный репозиторий используется также для ограниченных Android-тестов
на временной машине GitHub: [фактические результаты и бюджет](server-capacity.md).
Пароли игровых аккаунтов в jobs не передаются; production-сбор на Actions
не запускается. Личный телефон для этих тестов не нужен.
